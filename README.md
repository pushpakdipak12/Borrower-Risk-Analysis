
# **📊 Borrower Risk Analysis: Understanding Default Rates & APR Trends**

## **📌 Introduction**

This report dives into a comprehensive analysis of borrower risk, examining key factors that influence default rates. Using metrics such as:

✔ Borrower APR (Annual Percentage Rate)✔ Employment Status✔ Income Range✔ Prosper Rating✔ Debt-to-Income (DTI) Ratio

The insights extracted from this analysis will help stakeholders refine their strategies for managing borrower portfolios, enhancing financial stability, and minimizing risks.

## **🔹 Key Insights & Metrics**

### **1️⃣ Borrower APR & Default Rate**

KPI: The average Borrower APR stands at 0.22, and the overall default rate is 0.15.

📊 Insight: These KPIs provide a baseline understanding of the cost of borrowing and the general risk of default across the portfolio.

🎯 Actionable Insight: Stakeholders should track APR trends to ensure balanced lending practices.

### ***2️⃣ Default Rate by Employment Status**

📌 Key Finding: Employment status significantly impacts default risk.

📊 Default Rate by Employment Status:

Retired (0.29) and Full-time (0.28) borrowers have higher default rates.

Employed individuals have the lowest default rate (0.06).

✅ Actionable Insight: Offer tailored financial support or conservative loan products to high-risk employment groups to mitigate defaults.

### **3️⃣ Average Borrower APR by Income Range**

📌 Finding: Lower-income borrowers face higher APRs.

📊 APR Breakdown by Income:

Borrowers earning $1-24,999 face the highest APR (0.25).

Borrowers earning $100,000+ enjoy a lower APR of 0.20.

✅ Actionable Insight: Financial institutions should consider reducing APR for lower-income borrowers who demonstrate consistent repayment behavior.

### **4️⃣ Default Rate by Prosper Rating (Alpha)**

📌 Finding: The Prosper rating is a strong predictor of borrower risk.

📊 Risk Trends by Prosper Rating:

HR (High Risk) borrowers have a default rate of 0.21.

AA-rated borrowers have a low default rate of 0.02.

✅ Actionable Insight: Favor borrowers with higher Prosper ratings while implementing stricter risk assessments for high-risk borrowers.

### **5️⃣ Default Rate by Debt-to-Income Ratio (DTI)**

📌 Finding: Higher DTI = Higher Default Risk

📊 Key Trends:

Default rates increase sharply as DTI exceeds 0.5.

DTI nearing 0.7 shows peak default rates.

✅ Actionable Insight: Implement stricter lending criteria for high-DTI borrowers and introduce personalized debt management services.

### **6️⃣ Sum of Borrower APR by Income Range**

📌 Finding: Lower-income borrowers have a higher APR burden.

📊 Key Metrics:

Mean APR: 3861.37

Median APR: 3456.98

Max APR: 7560.32

Min APR: 130.86

✅ Actionable Insight: Financial institutions should rethink loan pricing strategies to provide fairer access to credit.

## **💡 Strategic Recommendations**

✅ 1. Employment Status Focus

Offer tailored loan products for high-risk employment groups.

Provide financial counseling for borrowers with uncertain income sources.

✅ 2. Income-Based Loan Adjustments

Lower APR for lower-income borrowers to encourage repayment.

Introduce financial literacy programs to reduce default risks.

✅ 3. Utilize Prosper Ratings for Smarter Lending

Prioritize loans to high-rated borrowers (AA, A, B).

Apply stricter assessments for HR-rated borrowers.

✅ 4. Strengthen DTI Management

Set thresholds for DTI acceptance to prevent over-indebtedness.

Offer debt restructuring options for high-DTI borrowers.
